Cómo enviar una plantilla

1. Consulta tus números y sus plantillas

GET /api/v1/external/whatsapp/connections
X-Api-Key: tu_clave

GET /api/v1/external/whatsapp/connections/{id}/templates
X-Api-Key: tu_clave

2. Envía

POST /api/v1/external/whatsapp/messages
X-Api-Key: tu_clave

{
  "clientId": "uuid-de-tu-sistema",
  "connectionId": "uuid-del-numero",
  "to": "573001234567",
  "template": {
    "name": "aviso_despacho",
    "language": "es_CO",
    "parameters": { "1": "Ana", "2": "4821" }
  }
}

Bandeja

El mensaje queda en el hilo del número. Si el cliente responde, le contesta un asesor o el bot, como siempre.

¿Revocar ERP Contable?
